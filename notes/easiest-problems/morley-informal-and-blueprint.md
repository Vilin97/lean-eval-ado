# Morley's categoricity theorem: informal proof and Lean blueprint

Target (`generated/morley_categoricity_theorem/Challenge.lean`):

```lean
theorem morley_categoricity_theorem
    (L : FirstOrder.Language.{0, 0}) (hL : L.card ≤ ℵ₀)
    (T : L.Theory) (hT : T.IsComplete)
    (hInf : ∀ M : FirstOrder.Language.Theory.ModelType.{0, 0, 0} T, Infinite M)
    {κ : Cardinal.{0}} (hκ : ℵ₀ < κ) (hcat : κ.Categorical T)
    {μ : Cardinal.{0}} (hμ : ℵ₀ < μ) :
    μ.Categorical T
```

with `Cardinal.Categorical κ T := ∀ M N : T.ModelType, #M = κ → #N = κ →
Nonempty (M ≃[L] N)` (`Mathlib/ModelTheory/Satisfiability.lean:507`) and
`T.IsComplete := T.IsSatisfiable ∧ ∀ φ, T ⊨ᵇ φ ∨ T ⊨ᵇ ∼φ` (ibid. 388).

Note the hypotheses are exactly the classical ones: countable language, complete
theory with only infinite models. Everything lives in `Type 0`, which matters:
`κ, μ : Cardinal.{0}`, so all the models being compared are `Type 0` and no
universe lifting is needed inside the argument.

# Part I — informal proof

Fix `L`, `T`, `κ` as in the statement. Write `𝔐` for the class of models of `T`.

## 1. Skeleton

The proof is the standard Baldwin–Lachlan-flavoured route:

```
κ-categorical
   │
   ├── (A) ⟹ T is ω-stable                    [uses EM models + a non-saturated model of size κ]
   │
   └── (B) ⟹ T has no Vaughtian pair          [uses the two-cardinal theorem]

ω-stable ⟹ (C) saturated models exist in every uncountable cardinality
ω-stable ⟹ (D) prime models over every set exist

(A)+(B) ⟹ (E) every model of T of uncountable cardinality μ is saturated

(C)+(E) + uniqueness of saturated models ⟹ μ-categorical
```

## 2. Preliminaries

**Definition 2.1 (types).** For `M ⊨ T` and `A ⊆ M`, `S_n^M(A)` is the set of
complete `n`-types over `A` consistent with `Th(M_A)`. Mathlib's
`T.CompleteType α` is exactly the space of complete types in the variables `α`
over the theory `T` in the language with constants `L[[α]]`; types over a
parameter set `A ⊆ M` are `(Th(M_A)).CompleteType (Fin n)`.

**Definition 2.2 (ω-stable).** `T` is ω-stable if for every `M ⊨ T` and every
countable `A ⊆ M`, `|S_1^M(A)| ≤ ℵ₀`.

**Definition 2.3 (saturated).** `M ⊨ T` is *saturated* if for every `A ⊆ M` with
`|A| < |M|`, every `p ∈ S_1^M(A)` is realised in `M`.

**Definition 2.4 (Vaughtian pair).** A *Vaughtian pair* for `T` is a pair of
models `N ≺ M`, `N ≠ M`, together with an `L`-formula `φ(x, ȳ)` and `b̄ ∈ N`
such that `φ(M, b̄) = φ(N, b̄)` is infinite.

**Theorem 2.5 (uniqueness of saturated models).** Two elementarily equivalent
saturated models of the same cardinality are isomorphic.

*Proof.* Back-and-forth on the two models, of length `|M|`. Enumerate
`M = {a_i}_{i<λ}`, `N = {b_i}_{i<λ}` and build an increasing chain of elementary
partial maps `f_i` with `|dom f_i| < λ`; at even stages extend the domain by
`a_i` using saturation of `N` (the type of `a_i` over the current, small, domain
is realised in `N`), at odd stages symmetrically. The union is an isomorphism. ∎

This is the only place uniqueness is used, and it is a pure back-and-forth: no
stability theory.

## 3. (A) `κ`-categorical ⟹ `T` is ω-stable

**Theorem 3.1 (Ehrenfeucht–Mostowski).** Let `T` be a theory with infinite
models in a language of size `≤ ℵ₀`. For every infinite linear order `(I, <)`
there is a model `EM(I) ⊨ T` generated by an `I`-indexed sequence of order
indiscernibles, with `|EM(I)| = |I| + ℵ₀`, and for every `A ⊆ EM(I)` with
`|A| ≤ λ` the number of types over `A` realised in `EM(I)` is `≤ λ + ℵ₀`.

*Proof.* Skolemise `L` to `L^{sk}` (still countable), and use Ramsey's theorem
plus compactness to find a model with an `I`-indexed order-indiscernible
sequence: the theory
`Th(M^{sk}) ∪ {φ(c_{i₁},…,c_{i_n}) ↔ φ(c_{j₁},…,c_{j_n}) : i₁<…<i_n, j₁<…<j_n}`
is finitely satisfiable, by Ramsey applied to the colouring of increasing
`n`-tuples from an infinite set by their `n`-type. Take `EM(I)` = the Skolem
hull of the indiscernible sequence. The type-counting clause holds because every
element of `EM(I)` is `t(c_{i₁},…,c_{i_n})` for a Skolem term `t`, and its type
over `A` is determined by `t` together with the finite order-type of
`{i₁,…,i_n}` relative to the (at most `λ`) indices occurring in `A`. ∎

**Theorem 3.2.** If `T` is `κ`-categorical for some `κ > ℵ₀` then `T` is
ω-stable.

*Proof.* Suppose not: there are `M ⊨ T` and a countable `A ⊆ M` with
`|S_1^M(A)| > ℵ₀`, hence `≥ ℵ₁`. By compactness and Löwenheim–Skolem build a
model `M₁ ⊨ T` of size `κ` realising `ℵ₁` distinct types over a countable
subset. On the other hand, `EM(κ)` from Theorem 3.1 has size `κ` and realises
only countably many types over each countable subset. By `κ`-categoricity
`M₁ ≅ EM(κ)`, contradiction. ∎

## 4. (C) ω-stable ⟹ saturated models exist in every cardinality `> ℵ₀`

**Theorem 4.1 (stability transfer).** If `T` is ω-stable then `T` is
`λ`-stable for every infinite `λ`: `|S_1^M(A)| ≤ λ` whenever `|A| ≤ λ`.

*Proof.* Via Morley rank, or directly: ω-stability implies the type space
`S_1^M(A)` is a scattered (hence, for `|A| ≤ λ`, cardinality `≤ λ`) totally
disconnected compact space. The standard argument uses the *binary tree
property*: if some `S_1^M(A)` with `|A| ≤ λ` had cardinality `> λ` then, by a
tree construction, there would be a binary tree `(φ_s)_{s ∈ 2^{<ω}}` of formulas
with parameters from a countable subset, each `φ_s` consistent and
`φ_{s0}, φ_{s1}` contradictory, giving `2^{ℵ₀} > ℵ₀` types over a countable set —
contradicting ω-stability. ∎

**Theorem 4.2.** If `T` is `λ`-stable for all infinite `λ` (in particular if `T`
is ω-stable) then for every `λ > ℵ₀` and every `M ⊨ T` there is a saturated
`N ⊨ T` with `|N| = λ` and `M ≺ N` when `|M| ≤ λ`.

*Proof.* Build an elementary chain `(M_i)_{i<λ}` of models of size `λ`, where
`M_{i+1}` realises every type over every subset of `M_i` of size `< λ` — possible
because there are at most `λ` such types by `λ`-stability, so `M_{i+1}` can be
taken of size `λ`. At limits take unions. If `λ` is regular the union is
saturated; for singular `λ` one instead builds a *special* model and uses that
special models of the same cardinality and theory are isomorphic. (This is the
one place where the argument bifurcates on cofinality; Morley's original proof
avoids it by proving directly that every model of uncountable size is saturated,
which is step (E) below.) ∎

## 5. (B) `κ`-categorical ⟹ no Vaughtian pairs

**Theorem 5.1 (Vaught's two-cardinal theorem).** If `T` has a Vaughtian pair
then `T` has a model of size `ℵ₁` in which some formula `φ(x, b̄)` defines a
countably infinite set.

*Proof.* From a Vaughtian pair `N ≺ M` build, by an elementary chain of length
`ω₁` in which each step is a copy of the pair, a model `M*` of size `ℵ₁` with
`φ(M*, b̄)` countable. (The classical proof passes through the two-sorted
"Vaughtian pair theory" and uses the omitting-types theorem to keep `φ(·,b̄)`
small.) ∎

**Theorem 5.2.** If `T` is `κ`-categorical, `κ > ℵ₀`, then `T` has no Vaughtian
pair.

*Proof.* Suppose it does. By Theorem 5.1 and Löwenheim–Skolem there is a model
`M₀` of size `κ` in which some `φ(x, b̄)` defines an infinite set of size `< κ`.
By ω-stability (Theorem 3.2) and Theorem 4.2 there is also a saturated model
`M₁` of size `κ`, in which every infinite definable set has size `κ`
(a definable infinite set in a saturated model is as large as the model, by
realising `κ` many types). `M₀ ≇ M₁`, contradicting categoricity. ∎

## 6. (E) ω-stable + no Vaughtian pairs ⟹ every uncountable model is saturated

**Theorem 6.1 (prime models over sets).** If `T` is ω-stable then over every
subset `A` of a model there is a *prime* model `M(A)`: `A ⊆ M(A) ≺ 𝔐` and
`M(A)` elementarily embeds over `A` into every model containing `A`.
Moreover `M(A)` is *atomic* over `A` (every finite tuple realises an isolated
type over `A`).

*Proof.* ω-stability implies every type space `S_n(A)` has isolated points
dense (otherwise build a binary tree of non-isolated conditions, producing
`2^{ℵ₀}` types over a countable set). Then construct `M(A)` as an increasing
union realising only isolated types. ∎

**Theorem 6.2.** Assume `T` is ω-stable with no Vaughtian pairs, and let
`M ⊨ T` with `|M| = μ > ℵ₀`. Then `M` is saturated.

*Proof.* Let `A ⊆ M`, `|A| < μ`, and `p ∈ S_1(A)`. Let `N ≺ M` be the prime
model over `A`, so `|N| ≤ |A| + ℵ₀ < μ`. Since `|M| > |N|` there is
`c ∈ M ∖ N`. "No Vaughtian pair" applied to `N ≺ M` forces every `L(A)`-formula
with infinitely many solutions in `N` to gain new solutions in `M`; a standard
argument then shows `M` realises every type over `A`. (Concretely: pick
`φ ∈ p`; the set `φ(M)` is infinite; if `p` were omitted in `M`, the pair
`(N', M)` for a suitable `N' ≺ M` containing `A` and all realisations of `p`'s
approximations would be Vaughtian.) ∎

## 7. Conclusion

Let `μ > ℵ₀` and let `M, N ⊨ T` with `|M| = |N| = μ`. By Theorem 3.2, `T` is
ω-stable; by Theorem 5.2, `T` has no Vaughtian pair; by Theorem 6.2, `M` and `N`
are both saturated of size `μ`. `T` is complete so `M ≡ N`, and Theorem 2.5
gives `M ≅ N`. Hence `μ.Categorical T`. ∎

*(The hypothesis `hInf` is used to know `T` has arbitrarily large models, and
`hL : L.card ≤ ℵ₀` is used in Theorems 3.1, 3.2, 4.1 and 6.1.)*

### `Saturated.lean` (do this first — it is self-contained)

```lean
def IsSaturated (M : T.ModelType) : Prop :=
  ∀ (A : Set M), #A < #M → ∀ p : (completeTheoryOver A).CompleteType (Fin 1),
    ∃ a : M, typeOf ![a] = p

theorem nonempty_equiv_of_isSaturated
    {M N : T.ModelType} (hM : IsSaturated M) (hN : IsSaturated N)
    (hcard : #M = #N) : Nonempty (M ≃[L] N)
```

Proof by transfinite back-and-forth over `Ordinal`, using
`Language.PartialEquiv` and its `IsExtensionPair` API. **~600 lines**, and it is
the one milestone that can be finished without any stability theory — worth
landing early as an independent, reusable result.

### `Ramsey.lean`

```lean
theorem exists_infinite_monochromatic {α : Type*} [Infinite α] (n : ℕ)
    {β : Type*} [Finite β] (c : {s : Finset α // s.card = n} → β) :
    ∃ (S : Set α), S.Infinite ∧ ∃ b, ∀ s : {s : Finset α // s.card = n},
      ↑s ⊆ S → c s = b
```

Mathlib has finite Ramsey but not the infinite pigeonhole-style version needed
here. Standard proof by induction on `n` with a nested-sequence construction.
**~300 lines.**

### `Indiscernibles.lean` + `EM.lean`

The compactness argument is routine given Mathlib's
`isSatisfiable_iff_isFinitelySatisfiable`; the type-counting lemma of §3.1 is
the technical core and needs a careful induction over Skolem terms.
**~1200 lines.**

### `Stable.lean` / `OmegaStable.lean`

The binary-tree argument. The delicate Lean point is the construction of the
tree by recursion on `List Bool` with a `Classical.choice` at each node.
**~1000 lines.**

### `Prime.lean`, `Chain.lean`, `Vaughtian.lean`, `Main.lean`

The two-cardinal theorem is the largest single piece and needs the omitting-types
theorem, which Mathlib also lacks. **~2500 lines** for these four together.

Compared with Ado this is fewer lines but *more* of them are genuinely new
infrastructure: Ado's missing pieces (PBW, Casimir, Levi) are textbook algebra
with a clear Lean shape, whereas the type-counting and two-cardinal arguments
involve set-theoretic constructions that are notoriously fiddly to formalise.
That is why Morley is ranked third rather than first.
