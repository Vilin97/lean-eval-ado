# Ado's theorem and the Ado–Iwasawa theorem: a complete informal proof

Targets:

* `adoCharZero` — for `K` a field of characteristic `0` and `L` a finite-dimensional
  Lie algebra over `K`, there are a finite-dimensional `K`-vector space `V` and an
  **injective** Lie algebra morphism `ρ : L →ₗ⁅K⁆ Module.End K V`.
* `adoIwasawa` — the same with no hypothesis on `char K`.

Throughout, `K` is a field, all Lie algebras and modules are finite-dimensional
over `K` unless said otherwise, and `𝔤` denotes a finite-dimensional Lie algebra.
We write `U(𝔤)` for the universal enveloping algebra, `ι : 𝔤 → U(𝔤)` for the
canonical map, and `J(𝔤) ⊆ U(𝔤)` for the augmentation ideal, i.e. the two-sided
ideal generated by `ι(𝔤)`. `𝔤¹ = 𝔤`, `𝔤^{i+1} = [𝔤, 𝔤^i]` is the lower central
series.

The two theorems share almost all of their content. The plan:

```
                    PBW  (§1)
                     │
        ┌────────────┼─────────────────────┐
        │            │                     │
   Birkhoff (§3)   char p: p-envelope   Noetherian/Cayley–Hamilton
        │            + restricted PBW (§7)      finiteness (§4)
        │                     │                     │
   nilpotent case             │                     │
        │                     │                     │
   solvable case (§5) ────────┼─────────────────────┘
        │                     │
   Levi (§6, char 0 only)     │
        │                     │
   general char 0 (§6)     general char p (§7)
        └──────────┬──────────┘
              adoIwasawa
                   │
              adoCharZero  (a special case)
```

Note the logical shape: `adoIwasawa` is *strictly stronger* than `adoCharZero`,
so the second benchmark problem is the first one plus §7. In characteristic `p`
the argument is genuinely **shorter** than in characteristic `0` — the whole
Levi/nilradical apparatus is replaced by a single finite-dimensionality fact
about restricted enveloping algebras.

## §0. The two standard reductions

**Lemma 0.1 (centre suffices).**
Let `σ : 𝔤 → 𝔤𝔩(W)` be a finite-dimensional representation with
`ker σ ∩ Z(𝔤) = 0`. Then `ad ⊕ σ : 𝔤 → 𝔤𝔩(𝔤 ⊕ W)` is faithful.

*Proof.* `ker(ad ⊕ σ) = ker(ad) ∩ ker σ = Z(𝔤) ∩ ker σ = 0`. ∎

**Lemma 0.2 (direct sums).** If `ρ₁ : 𝔤 → 𝔤𝔩(V₁)` and `ρ₂ : 𝔤 → 𝔤𝔩(V₂)` are
representations then so is `ρ₁ ⊕ ρ₂` on `V₁ ⊕ V₂`, and
`ker(ρ₁ ⊕ ρ₂) = ker ρ₁ ∩ ker ρ₂`. ∎

So it always suffices to produce a representation faithful on the centre.

## §1. Poincaré–Birkhoff–Witt

This is the one large ingredient that Mathlib does not have at all.

**Theorem 1.1 (PBW).** Let `𝔤` be a Lie algebra over a commutative ring `R`
which is **free** as an `R`-module with an ordered basis `(x_i)_{i ∈ ι}`, `ι`
linearly ordered. Then the *standard monomials*

```
x_{i₁} x_{i₂} … x_{i_m},        i₁ ≤ i₂ ≤ … ≤ i_m,   m ≥ 0
```

form an `R`-basis of `U(𝔤)`.

For us `R = K` is a field and `𝔤` is finite-dimensional, so `ι = Fin n`.

*Proof (the classical "action on the symmetric algebra" proof).*
Let `S = K[y_1, …, y_n]` be a polynomial ring, graded by total degree, with the
standard monomials `y_A = y_{i₁} ⋯ y_{i_m}` (`i₁ ≤ … ≤ i_m`) as a basis, indexed
by nondecreasing sequences `A`. Write `i ≤ A` when `i ≤ i₁`, and `S_{≤m}` for the
span of the `y_A` with `|A| ≤ m`.

*Claim.* There is a unique bilinear map `𝔤 × S → S`, written `x_i · f`,
satisfying

* (P1) `x_i · y_A = y_i y_A` whenever `i ≤ A`;
* (P2) `x_i · y_A ≡ y_i y_A  (mod S_{≤|A|})` for all `A`;
* (P3) `x_i · (x_j · y_A) − x_j · (x_i · y_A) = [x_i, x_j] · y_A` for all `i, j, A`.

The claim is proved by induction on `|A|`, and within that by induction on `i`.
For `i ≤ A` the value is forced by (P1). Otherwise write `A = (j, B)` with
`j < i` and `j ≤ B`, so `y_A = y_j y_B = x_j · y_B` by (P1). Then (P3) forces

```
x_i · y_A = x_i · (x_j · y_B) = x_j · (x_i · y_B) + [x_i, x_j] · y_B,
```

and both right-hand terms are already defined by the inductive hypotheses
(`x_i · y_B` is defined since `|B| < |A|`, and it lies in `y_i y_B + S_{≤|B|}`,
so `x_j · (x_i · y_B)` is covered by the induction on `|A|` together with (P2)).
Existence of the map is this recursion; the only thing to check is that (P3)
then holds for *all* `i, j, A`, which is the usual case analysis (the only
non-immediate case is `i > j` and `j > A`, where the Jacobi identity is used
exactly once). Property (P2) is preserved because
`[x_i,x_j] · y_B ∈ S_{≤|B|+1} ⊆ S_{≤|A|}`.

By (P3) the map `x ↦ (f ↦ x · f)` is a Lie algebra morphism `𝔤 → 𝔤𝔩(S)`,
hence extends to an algebra morphism `Φ : U(𝔤) → End_K(S)`.

Standard monomials **span** `U(𝔤)`: by induction on degree, using
`x_j x_i = x_i x_j + [x_j, x_i]` to sort.

Standard monomials are **independent**: if `Σ_A c_A x_A = 0` in `U(𝔤)`, apply
`Φ` to `1 ∈ S`. By (P1)+(P2) and induction, `Φ(x_A)(1) = y_A + (lower order)`,
so `Σ_A c_A (y_A + …) = 0` in `S` forces, by looking at the top degree and
downward induction, `c_A = 0` for all `A`. ∎

**Corollary 1.2.** `ι : 𝔤 → U(𝔤)` is injective.

*Proof.* `ι(x)` is the standard monomial of the length-one word `x`, and
distinct basis elements give distinct standard monomials. ∎

> **Correction (2026-08-04).** An earlier version of this note also asserted
> `ι(𝔤) ∩ J(𝔤)² = ⊥`, where `J(𝔤)` is the augmentation *ideal*. **That is
> false.** Since `ι` is a Lie morphism,
> `ι ⁅x, y⁆ = ι x · ι y − ι y · ι x ∈ J²`, so every nonzero bracket is a
> counterexample; if `𝔤` is perfect then `ι(𝔤) ⊆ J²` and in fact `J = J²`.
> The confusion was between the augmentation-ideal powers `J^m` and the PBW
> *filtration* `U_{≤m}` (the span of standard monomials of length `≤ m`), which
> are different objects. PBW controls the latter:
> `U_{≤m}/U_{≤m−1} ≅ Sym^m(𝔤)`, and `ι(𝔤) ∩ U_{≤0} = ⊥`.
> The formalised results in `Truncation.lean` are unaffected — `U(𝔤) ⧸ augPow k`
> is finite-dimensional as proved — but note `augPow` can collapse
> (`augPow k = augPow 1` for perfect `𝔤`), so it is only informative in the
> nilpotent range, which is where §3 uses it.

**Corollary 1.3.** `U_{≤m}` is finite-dimensional, of dimension
`#{A : |A| ≤ m}`.

**Corollary 1.4.** `U(𝔤)` is left and right Noetherian.
*Proof.* `gr U(𝔤) ≅ Sym(𝔤)` is Noetherian, and a filtered ring whose associated
graded is Noetherian is Noetherian. ∎

## §2. Structure theory inputs

**Definition 2.1 (nilradical).** `nil(𝔤)` is the sum of all nilpotent ideals of
`𝔤`. It is a nilpotent ideal (the sum of two nilpotent ideals is nilpotent), and
it is characteristic: `D(nil 𝔤) ⊆ nil 𝔤` for every derivation `D`, because
`D(𝔞)` is contained in the nilpotent ideal `𝔞 + D(𝔞)` whenever `𝔞` is a
nilpotent ideal. Also `Z(𝔤) ⊆ nil(𝔤)`.

**Theorem 2.2 (char 0).** `[𝔤, 𝔤] ∩ rad(𝔤)` is a nilpotent ideal, hence
`[𝔤, 𝔤] ∩ rad(𝔤) ⊆ nil(𝔤)`. In particular `[rad 𝔤, rad 𝔤] ⊆ nil 𝔤`, so
`rad(𝔤)/nil(𝔤)` is abelian.

*Proof.* Put `𝔯 = rad 𝔤`, `𝔥 = [𝔤,𝔤] ∩ 𝔯`. Let `ρ : 𝔤 → 𝔤𝔩(V)` be any
finite-dimensional representation. By Lie's theorem (char 0, after passing to
`K̄`) `ρ(𝔯)` is simultaneously upper-triangularisable, so `ρ([𝔤,𝔤] ∩ 𝔯)` is
strictly upper triangular, i.e. consists of nilpotent operators. Applying this
to `ρ = ad` shows `ad(𝔥)` consists of nilpotent operators, so `𝔥` is nilpotent
by Engel's theorem. ∎

**Corollary 2.3.** For char `0` and any derivation `D` of `𝔤`,
`D(rad 𝔤) ⊆ nil(𝔤)`.

*Proof.* Form `𝔤' = 𝔤 ⋊ K·D`. Then `rad(𝔤') ⊇ rad(𝔤)` and
`D(rad 𝔤) ⊆ [𝔤', 𝔤'] ∩ rad(𝔤')`, which is nilpotent by 2.2 and is an ideal of
`𝔤`, hence lies in `nil(𝔤)`. ∎

*(Special case used below: for `H ∈ 𝔯` solvable and `𝔞 ⊆ 𝔯` an ideal,
`[H, 𝔞] ⊆ [𝔯,𝔯] ⊆ nil(𝔯)`.)*

**Theorem 2.4 (Engel, in Mathlib).** A Lie subalgebra of `𝔤𝔩(V)` consisting of
nilpotent endomorphisms is simultaneously strictly upper-triangularisable; in
particular the associative subalgebra it generates is nilpotent.

**Corollary 2.5.** Let `ρ : 𝔞 → 𝔤𝔩(V₀)` be finite-dimensional with `𝔫 ⊆ 𝔞` an
ideal such that `ρ(𝔫)` consists of nilpotent operators. Let `B ⊆ End(V₀)` be the
unital associative algebra generated by `ρ(𝔞)`, and `𝔦 = B ρ(𝔫) B`. Then `𝔦` is
a **nilpotent** ideal of `B`: `𝔦^N = 0` for some `N`.

*Proof.* `ρ(𝔫)` is an ideal of the Lie algebra `ρ(𝔞)`, so by Engel there is a
full flag `0 = V_0 ⊂ … ⊂ V_d = V₀` stable under `ρ(𝔞)` with `ρ(𝔫) V_j ⊆ V_{j−1}`.
Then `B` preserves the flag and `𝔦 V_j ⊆ V_{j−1}`, so `𝔦^d = 0`. ∎

## §3. The nilpotent case (Birkhoff)

**Theorem 3.1 (Birkhoff).** Let `𝔫` be a finite-dimensional nilpotent Lie
algebra over any field `K`, with `𝔫^{c+1} = 0`. Put `k = max(c+1, 2)` and

```
W := U(𝔫) / J(𝔫)^k,     σ : 𝔫 → 𝔤𝔩(W),  σ(x) = left multiplication by x.
```

Then `W` is finite-dimensional, `σ` is a Lie algebra morphism, `σ` is injective,
and `σ(x)` is nilpotent for every `x ∈ 𝔫` (indeed `σ(x₁)⋯σ(x_k) = 0`).

*Proof.* `W` is finite-dimensional by `Truncation.lean`. `σ` is a morphism
because `L_x L_y − L_y L_x = L_{xy − yx} = L_{[x,y]}` in `U(𝔫)`. Faithfulness
needs `ι(𝔫) ∩ J^k = ⊥`, which for *nilpotent* `𝔫` holds once `k` exceeds the
nilpotency class — see the correction under Corollary 1.2; it is **not** true at
`k = 2`. Finally `σ(x₁)⋯σ(x_k) = L_{x₁⋯x_k}` and `x₁⋯x_k ∈ J^k`. ∎

> **Superseded (2026-08-04).** This route is no longer used. The nilpotent case
> is now supplied by the port of `Komyyy/ado`, whose induction obtains
> faithfulness from the inductive hypothesis rather than from any injectivity
> statement about `ι`, and therefore needs no PBW input at all. See
> `Submission/Ado/Port/Nilpotent.lean` and the bridge
> `Submission.Ado.exists_faithful_nilpotent_rep`.

## §4. The extension step

This is the engine of the whole proof; both the solvable induction (§5) and the
semisimple step (§6) are instances of it.

**Setup 4.1.** Let `𝔞` be a finite-dimensional Lie algebra, `𝔫 ⊆ 𝔞` an ideal,
and `ρ₀ : 𝔞 → 𝔤𝔩(V₀)` a finite-dimensional representation such that

* `ρ₀` is injective, and
* `ρ₀(𝔫)` consists of nilpotent operators.

Let `π : U(𝔞) → End(V₀)` be the algebra morphism extending `ρ₀`, let
`𝔮 = ker π`, and let

```
I := 𝔮 + U(𝔞)·ι(𝔫)·U(𝔞)      (a two-sided ideal of U(𝔞)).
```

**Lemma 4.2.** There is `N ≥ 1` with `I^N ⊆ 𝔮`.

*Proof.* `U(𝔞)/𝔮 ≅ B`, the associative envelope of `ρ₀(𝔞)`, and the image of `I`
in `B` is `𝔦 = Bρ₀(𝔫)B`, nilpotent by Corollary 2.5. ∎

**Lemma 4.3 (finite dimensionality).** `U(𝔞)/I^m` is finite-dimensional for
every `m`.

*Proof.* `U(𝔞)/I` is a quotient of `B ⊆ End(V₀)`, hence finite-dimensional.
`U(𝔞)` is Noetherian (1.4), so `I` is a finitely generated two-sided ideal, and
`I^j/I^{j+1}` is a finitely generated `U(𝔞)/I`-bimodule, hence
finite-dimensional. Induct on `m`. ∎

*(Alternative, avoiding Noetherianity: by Cayley–Hamilton each basis element
`x_i` of `𝔞` satisfies a monic polynomial `P_i` with `π(P_i(x_i)) = 0`, so
`P_i(x_i) ∈ 𝔮 ⊆ I`; hence modulo `I^m` every PBW monomial reduces to one of
bounded degree.)*

**Lemma 4.4 (derivations preserve `I^m`).** Let `D` be a derivation of `𝔞` with
`D(𝔞) ⊆ 𝔫`. Extend `D` to the unique derivation `D̃` of `U(𝔞)` with `D̃|_𝔞 = D`
(exists by the universal property applied to `𝔞 → U(𝔞) ⋉ U(𝔞)`, concretely
`D̃(a₁⋯a_m) = Σ_i a₁⋯D(a_i)⋯a_m`). Then `D̃(U(𝔞)) ⊆ I` and hence
`D̃(I^m) ⊆ I^m` for every `m ≥ 1`.

*Proof.* `D̃` kills `K·1` and sends each monomial `a₁⋯a_m` into
`Σ_i a₁⋯ D(a_i) ⋯ a_m ⊆ U·ι(𝔫)·U ⊆ I`. For the second claim, write
`x ∈ I^m` as a sum of products `u₁⋯u_m` with `u_i ∈ I`; Leibniz gives
`D̃(u₁⋯u_m) = Σ_i u₁⋯D̃(u_i)⋯u_m`, and `D̃(u_i) ∈ I`, so each term is in `I^m`. ∎

**Proposition 4.5 (extension).** In Setup 4.1, let `𝔡` be a Lie algebra of
derivations of `𝔞` (a Lie subalgebra of `Der(𝔞)`) with `D(𝔞) ⊆ 𝔫` for all
`D ∈ 𝔡`. Fix `m ≥ N` (Lemma 4.2) and put `W := U(𝔞)/I^m`. Then

```
τ : 𝔞 ⋊ 𝔡 → 𝔤𝔩(W),      τ(a, D) = L_a + D̃
```

is a Lie algebra morphism; its restriction to `𝔞` is injective; and `τ(x)` is
nilpotent for every `x ∈ 𝔫`.

*Proof.* `[D̃, L_a] = L_{D̃(a)}` for any derivation `D̃` of an algebra `A` acting
on itself: `D̃(a w) − a D̃(w) = D̃(a) w`. Hence

```
[τ(a,D), τ(b,E)] = [L_a, L_b] + [L_a, Ẽ] + [D̃, L_b] + [D̃, Ẽ]
                 = L_{ab − ba} − L_{E(a)} + L_{D(b)} + \widetilde{[D,E]}
                 = L_{[a,b] + D(b) − E(a)} + \widetilde{[D,E]}
                 = τ([a,b] + D(b) − E(a), [D,E]) = τ([(a,D),(b,E)]).
```

`τ` is well defined by Lemma 4.4. Injectivity on `𝔞`: if `L_a = 0` on `W` then
`a ∈ I^m ⊆ 𝔮`, and `𝔞 ∩ 𝔮 = ker ρ₀ = 0`. Nilpotency: for `x ∈ 𝔫`,
`L_x^m = L_{x^m}` and `x^m ∈ I^m`. ∎

**Remark 4.6.** The obstruction that makes Ado hard is now visible. To turn
Proposition 4.5 into a representation of a bigger Lie algebra `𝔤 ⊇ 𝔞` one needs
a Lie algebra morphism `𝔤 → 𝔞 ⋊ 𝔡` restricting to `a ↦ (a, 0)` on `𝔞`. Writing
`𝔤 = 𝔞 ⊕ 𝔪` as vector spaces and sending `a + u ↦ (a, ad u|_𝔞)`, the bracket
condition holds on `𝔞 × 𝔞` and on `𝔞 × 𝔪` unconditionally, and on `𝔪 × 𝔪` it
holds **iff `𝔪` is a subalgebra**. This is why the proof proceeds either

* one dimension at a time (`dim 𝔪 = 1`, automatically a subalgebra) — §5, or
* along a Levi complement (`𝔪 = 𝔰` semisimple, a subalgebra by Levi) — §6.

## §5. The solvable case

**Theorem 5.1.** Let `char K = 0` and let `𝔯` be a finite-dimensional solvable
Lie algebra with nilradical `𝔫`. Then there is a finite-dimensional faithful
representation `ρ : 𝔯 → 𝔤𝔩(V)` with `ρ(𝔫)` nilpotent.

*Proof.* Induction on `dim 𝔯 − dim 𝔫`.

*Base `𝔯 = 𝔫`.* Theorem 3.1.

*Step.* Suppose `𝔫 ⊊ 𝔯`. By Theorem 2.2, `[𝔯,𝔯] ⊆ 𝔫`, so every subspace of `𝔯`
containing `𝔫` is an ideal. Choose a codimension-one subspace `𝔞` with
`𝔫 ⊆ 𝔞 ⊊ 𝔯`, and `H ∈ 𝔯 ∖ 𝔞`, so `𝔯 = 𝔞 ⊕ K·H` and `𝔞` is an ideal.

`𝔫` is the nilradical of `𝔞` as well: `nil(𝔞) ⊇ 𝔫`, and `nil(𝔞)` is a
characteristic ideal of `𝔞`, hence (as `𝔞 ⊴ 𝔯`) an ideal of `𝔯`, hence
`nil(𝔞) ⊆ nil(𝔯) = 𝔫`.

By induction there is `ρ₀ : 𝔞 → 𝔤𝔩(V₀)` faithful with `ρ₀(𝔫)` nilpotent. Apply
Setup 4.1 to `(𝔞, 𝔫, ρ₀)`. Let `D = ad H|_𝔞`, a derivation of `𝔞`. By
Theorem 2.2, `D(𝔞) = [H, 𝔞] ⊆ [𝔯,𝔯] ⊆ 𝔫`. So `𝔡 = K·D` satisfies the
hypothesis of Proposition 4.5, and `𝔡` is one-dimensional, hence a subalgebra of
`Der(𝔞)`. Pick `m ≥ N` with additionally `m ≥ 2`, put `W = U(𝔞)/I^m` and

```
ρ(a + tH) := L_a + t·D̃      (a ∈ 𝔞, t ∈ K).
```

By Remark 4.6 with `𝔪 = K·H` (a subalgebra since `[H,H]=0`), `ρ` is a Lie
algebra morphism.

*Faithfulness.* Suppose `ρ(a + tH) = 0`. Evaluating at `1 ∈ W` gives
`a ∈ I^m ⊆ 𝔮`, hence `a = 0` (Proposition 4.5). So `t·D̃ = 0` on `W`. If `t ≠ 0`
then `D̃ = 0`, so for every `b ∈ 𝔞`, `[H,b] = D(b) ∈ I^m ∩ 𝔞 = 0`; thus `H`
centralises `𝔞`, so `K·H + Z(𝔞)`… more directly: then `𝔯 = 𝔞 ⊕ KH` has `H`
central, so `K·H` is a central — hence nilpotent — ideal of `𝔯`, so `H ∈ nil(𝔯)
= 𝔫 ⊆ 𝔞`, contradicting `H ∉ 𝔞`. Hence `t = 0`.

*Nilpotency on `𝔫`.* Proposition 4.5. ∎

## §6. The general case, characteristic zero

**Theorem 6.1 (Levi).** `char K = 0`, `𝔤` finite-dimensional, `𝔯 = rad 𝔤`. Then
there is a semisimple subalgebra `𝔰 ⊆ 𝔤` with `𝔤 = 𝔰 ⊕ 𝔯` as vector spaces.

*Proof sketch (the standard cohomological one).* Reduce to the case where `𝔯` is
abelian and is a minimal ideal, by induction on `dim 𝔯`. Then `𝔯` is a
`𝔤/𝔯`-module, and complements to `𝔯` in `𝔤` correspond to `1`-cocycles modulo
coboundaries, i.e. to `H¹(𝔤/𝔯, 𝔯)`. Whitehead's first lemma says
`H¹(𝔰, M) = 0` for `𝔰` semisimple and `M` finite-dimensional, which follows from
Weyl's complete reducibility theorem, which in turn follows from the
non-degeneracy of the Killing form (Cartan's criterion) via the Casimir element.
∎

**Theorem 6.2 (Ado, char 0).** Every finite-dimensional Lie algebra `𝔤` over a
field of characteristic `0` has a faithful finite-dimensional representation.

*Proof.* Let `𝔯 = rad 𝔤` and `𝔫 = nil 𝔤`. Note `nil 𝔯 = 𝔫` (same argument as in
§5: `nil 𝔯` is characteristic in `𝔯 ⊴ 𝔤`, hence an ideal of `𝔤`).

By Theorem 5.1 there is `ρ₀ : 𝔯 → 𝔤𝔩(V₀)` faithful with `ρ₀(𝔫)` nilpotent.
Apply Setup 4.1 to `(𝔞, 𝔫, ρ₀) = (𝔯, 𝔫, ρ₀)`, giving `𝔮`, `I`, `N`.

By Levi write `𝔤 = 𝔰 ⊕ 𝔯` with `𝔰` a subalgebra. For `s ∈ 𝔰`, `D_s := ad s|_𝔯`
is a derivation of `𝔯`, and

```
D_s(𝔯) = [s, 𝔯] ⊆ [𝔤,𝔤] ∩ 𝔯 ⊆ 𝔫
```

by Theorem 2.2. Also `s ↦ D_s` is a Lie algebra morphism `𝔰 → Der(𝔯)` because
`𝔰` is a subalgebra. Hence `𝔡 = {D_s : s ∈ 𝔰}` satisfies the hypotheses of
Proposition 4.5, and with `m ≥ max(N,2)`, `W = U(𝔯)/I^m`, we get a Lie algebra
morphism

```
τ : 𝔤 = 𝔯 ⊕ 𝔰 → 𝔤𝔩(W),      τ(a + s) = L_a + D̃_s,
```

well defined and a morphism by Remark 4.6 (with `𝔪 = 𝔰`, a subalgebra).

*Kernel of `τ`.* If `τ(a+s) = 0`, evaluate at `1`: `a ∈ I^m ⊆ 𝔮`, so `a = 0`.
Then `D̃_s = 0`, so `[s, b] ∈ I^m ∩ 𝔯 = 0` for all `b ∈ 𝔯`, i.e.
`s ∈ 𝔠 := C_𝔰(𝔯)`. So `ker τ ⊆ 𝔰`.

*Conclusion.* `Z(𝔤)` is an abelian ideal, hence `Z(𝔤) ⊆ 𝔯`. Therefore
`ker τ ∩ Z(𝔤) ⊆ 𝔰 ∩ 𝔯 = 0`, and Lemma 0.1 gives that `τ ⊕ ad` is a faithful
finite-dimensional representation of `𝔤`. ∎

## §7. The general case, positive characteristic (Iwasawa)

Here Levi's theorem is unavailable (and false), but a much cheaper route exists.

**Definition 7.1.** A **restricted** Lie algebra over `K` with `char K = p > 0`
is a Lie algebra `𝔤` with a map `x ↦ x^{[p]}` satisfying, for `a ∈ K`,
`x, y ∈ 𝔤`:

* `(a x)^{[p]} = a^p x^{[p]}`,
* `ad(x^{[p]}) = (ad x)^p`,
* `(x + y)^{[p]} = x^{[p]} + y^{[p]} + Σ_{i=1}^{p−1} s_i(x,y)`, where
  `i · s_i(x,y)` is the coefficient of `t^{i−1}` in `ad(t x + y)^{p−1}(x)`.

The model example: any associative `K`-algebra `A` is restricted with
`x^{[p]} = x^p`; in particular `𝔤𝔩(V)`.

**Definition 7.2 (restricted enveloping algebra).** For `𝔤` restricted, put
`u(𝔤) := U(𝔤)/⟨x^p − x^{[p]} : x ∈ 𝔤⟩`.

**Theorem 7.3 (restricted PBW).** If `𝔤` is restricted with ordered basis
`x_1, …, x_n`, then the monomials `x_1^{a_1} ⋯ x_n^{a_n}` with `0 ≤ a_i < p`
form a `K`-basis of `u(𝔤)`. In particular `dim_K u(𝔤) = p^n` and the composite
`𝔤 → U(𝔤) → u(𝔤)` is **injective**.

*Proof.* Same technique as Theorem 1.1: the elements `x^p − x^{[p]}` are central
in `U(𝔤)` (because `ad(x^p) = (ad x)^p = ad(x^{[p]})` on `𝔤` and `𝔤` generates
`U(𝔤)`), so `⟨x_i^p − x_i^{[p]}⟩` is the ideal generated by the central elements
`z_i := x_i^p − x_i^{[p]}`. By PBW, `U(𝔤)` is free over the central polynomial
subalgebra `K[z_1,…,z_n]` on the monomials `x^a`, `0 ≤ a_i < p`; quotienting by
`(z_1,…,z_n)` leaves exactly those monomials as a basis. ∎

**Lemma 7.4 (finite-dimensional `p`-envelope).** Every finite-dimensional Lie
algebra `𝔤` over `K` with `char K = p > 0` embeds as an ideal into a
finite-dimensional **restricted** Lie algebra `𝔤̂`.

*Proof.* `𝔤𝔩(𝔤) = End_K(𝔤)` is restricted, and `ad : 𝔤 → 𝔤𝔩(𝔤)` has kernel
`Z(𝔤)`. Let `𝔥 ⊆ 𝔤𝔩(𝔤)` be the restricted subalgebra generated by `ad(𝔤)`, i.e.
the span of `ad(𝔤)` together with all iterated `p`-th powers; it is a subspace of
the finite-dimensional `𝔤𝔩(𝔤)`, hence finite-dimensional, and `ad(𝔤)` is an
ideal of `𝔥` (since `[ad(x)^{p}, ad y] = (ad(ad x))^p(ad y) ∈ ad(𝔤)` as `ad 𝔤`
is an ideal of `𝔥` — argue by induction on the number of `p`-th powers).

Choose a subspace `W ⊆ 𝔥` with `𝔥 = ad(𝔤) ⊕ W`. Set `𝔤̂ := 𝔤 ⊕ W` as a vector
space, with bracket

```
[(x, w), (x', w')] := ( [x,x'] + w·x' − w'·x ,  [w,w']_{𝔥} mod ad 𝔤 -part folded back )
```

precisely: `𝔤̂` is defined as the pullback of `𝔤 ↠ ad 𝔤 ↪ 𝔥` along `𝔥`, i.e.

```
𝔤̂ := {(x, h) ∈ 𝔤 × 𝔥 : ad x = image of h in 𝔥/…}
```

Concretely take `𝔤̂ := (𝔤 × 𝔥)/{(x, −ad x) : x ∈ 𝔤 with ad x = 0}`… The standard
construction (Strade–Farnsteiner, Thm. 2.5.8) produces a restricted `𝔤̂` with
`𝔤 ⊴ 𝔤̂` and `dim 𝔤̂ ≤ dim 𝔤 + dim 𝔥`. Its `p`-map is defined by
`(x, w)^{[p]} := ((x,w)^{p}\text{-part in } 𝔤, (ad(x,w))^p)`, using that
`ad(x,w)^p ∈ 𝔥`. ∎

**Theorem 7.5 (Ado–Iwasawa, char `p`).** Every finite-dimensional Lie algebra
`𝔤` over a field of characteristic `p > 0` has a faithful finite-dimensional
representation.

*Proof.* Embed `𝔤 ⊆ 𝔤̂` with `𝔤̂` restricted and finite-dimensional (7.4). By
7.3, `u(𝔤̂)` is a finite-dimensional associative algebra and
`𝔤̂ → u(𝔤̂)` is injective. Left multiplication gives a faithful representation
`𝔤̂ → 𝔤𝔩(u(𝔤̂))` (faithful because `u(𝔤̂)` is unital: `L_x = 0 ⟹ x = L_x(1) = 0`).
Restrict to `𝔤`. ∎

**Theorem 7.6 (Ado–Iwasawa).** Every finite-dimensional Lie algebra over any
field has a faithful finite-dimensional representation: Theorem 6.2 if
`char K = 0`, Theorem 7.5 if `char K = p > 0`. ∎
