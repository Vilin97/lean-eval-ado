## The route, avoiding restricted Lie algebras entirely

The textbook proof (Strade–Farnsteiner) goes through restricted Lie algebras,
the restricted enveloping algebra `u(𝔤)`, restricted PBW, and a
finite-dimensional `p`-envelope. That is four new theories. The route below
replaces all of it with one construction inside `U(L)` itself, and reuses the
bridge already proved in `Submission/Ado/Embed.lean`:

```lean
theorem hasFaithfulFinRep_of_injective_toAlgebra
    (A) [Ring A] [Algebra K A] [FiniteDimensional K A]
    (f : L →ₗ⁅K⁆ A) (hf : Function.Injective f) : HasFaithfulFinRep K L
```

So it suffices to embed `L` into *some* finite-dimensional associative
`K`-algebra. We take `A := U(L) / I` for an explicit ideal `I` generated by
central elements.

### Step 1. `ad` commutes with `p`-th powers

**Lemma 1.1.** Let `A` be an associative ring of characteristic `p`, `a ∈ A`.
Then `ad(a)^p = ad(a^p)`, where `ad(a) b = a*b - b*a`.

*Proof.* `ad a = L_a - R_a` with `L_a b = a*b` and `R_a b = b*a`; `L_a` and
`R_a` commute (associativity). In a commutative subring of characteristic `p`,
`(u - v)^p = u^p - v^p`. Hence `ad(a)^p = L_a^p - R_a^p = L_{a^p} - R_{a^p} =
ad(a^p)`. ∎

In Lean: work in `Module.End K A`, use `Commute.sub_pow_char`, and
`LinearMap.mul_eq_comp` bookkeeping. `L_a^p = L_{a^p}` and `R_a^p = R_{a^p}`
are immediate inductions.

**Corollary 1.2.** `ad(a)^{p^i} = ad(a^{p^i})` for all `i`, by induction.

### Step 2. Central elements of `U(L)`

Fix `x ∈ L`. `ad_L x ∈ End_K L` and `End_K L` is finite-dimensional, so the
family `((ad_L x)^{p^i})_{i ≥ 0}` is linearly dependent. Let `m ≥ 1` be least
with

```
(ad_L x)^{p^m} = Σ_{i < m} λ_i · (ad_L x)^{p^i},    λ_i ∈ K.                (∗)
```

(such an `m` exists and `m ≤ 1 + dim End_K L`; take `m ≥ 1` even when `ad_L x`
is already in the span for `m = 0`, i.e. when `x` is central — this matters,
see the warning below).

**Lemma 2.1.** `c_x := (ι x)^{p^m} - Σ_{i<m} λ_i (ι x)^{p^i}` is central in
`U(L)`.

*Proof.* `ad_{U(L)}` is `K`-linear, and by Corollary 1.2
`ad_{U(L)}((ι x)^{p^i}) = (ad_{U(L)} (ι x))^{p^i}`. Since `ι` is a Lie
morphism, `ad_{U(L)}(ι x)` restricted to `ι(L)` is `ι ∘ ad_L x`. So by (∗),
`ad_{U(L)}(c_x)` vanishes on `ι(L)`. But `ad_{U(L)}(c_x)` is a derivation of
`U(L)` and `ι(L)` generates `U(L)` as a `K`-algebra
(`Submission.Ado.adjoin_range_ι_eq_top`, already proved), so it vanishes
identically. ∎

**Warning.** If `x` is central then `ad_L x = 0` and the least `m` is `0`,
giving `c_x = ι x`; the ideal would then kill `x`. Always take `m ≥ 1`. With
`m ≥ 1` and `x` central, `c_x = (ι x)^{p^m}`, which is harmless.

**Lemma 2.2 (uniform exponent).** One may take the *same* `m` for every basis
vector. If `(ad x)^{p^{m'}} = Σ_{i<m'} λ_i (ad x)^{p^i}` and `m ≥ m'`, raise
to the `p^{m-m'}`-th power: since the `(ad x)^{p^i}` all commute and the
characteristic is `p`,

```
(ad x)^{p^m} = Σ_{i<m'} λ_i^{p^{m-m'}} (ad x)^{p^{i+m-m'}},
```

and every exponent `i + m − m' < m`. ∎

So fix `q := p^m` with `m ≥ 1` uniform over a basis `x_1, …, x_n` of `L`, and
let `c_j := c_{x_j}`, `I := ideal generated by c_1, …, c_n` (a two-sided ideal,
since the `c_j` are central), and `A := U(L)/I`.

### Step 3. Poincaré–Birkhoff–Witt

This is the whole cost of the project. Two halves.

#### 3a. Ordered monomials span (no new ideas, but real work)

**Lemma 3.1.** With `x_1 < ⋯ < x_n` a basis of `L`, the ordered monomials
`ι(x_1)^{a_1} ⋯ ι(x_n)^{a_n}` span `U(L)` over `K`.

*Proof.* `ι(L)` generates `U(L)` as an algebra
(`adjoin_range_ι_eq_top`), so words in the `ι(x_i)` span. Sort each word by
adjacent transpositions: `ι(x_i) ι(x_j) = ι(x_j) ι(x_i) + ι⁅x_i, x_j⁆`, and the
correction term is a *shorter* word. Induct on (length, number of inversions),
lexicographically. ∎

#### 3b. Linear independence — the PBW module

Let `P := MvPolynomial (Fin n) K`, with monomial basis `z^a` indexed by
`a : Fin n →₀ ℕ` (`MvPolynomial.basisMonomials`). Write `|a| := Σ_i a i`, and
`i ≤ a` for `∀ j ∈ a.support, i ≤ j`. Let `P_{≤m}` be the span of the `z^a`
with `|a| ≤ m`. Write `⁅x_i, x_j⁆ = Σ_k γ_{ijk} x_k`.

**Construction 3.2.** Define `act : Fin n → (Fin n →₀ ℕ) → P` by well-founded
recursion on `|a|`:

```
act i a = if i ≤ a then z_i * z^a
          else  let j := min a.support   -- j < i, and j ≤ a - e_j
                z_j * (act i (a - e_j)) + Σ_k γ_{ijk} * act k (a - e_j)
```

Both recursive calls have argument of degree `|a| − 1`, so this is structural
recursion on `|a|` — **no lexicographic measure is needed**, which is the one
piece of good news about this construction. Extend to `L →ₗ[K] P →ₗ[K] P` by
linearity in both arguments.

**Lemma 3.3 (A).** `i ≤ a → x_i · z^a = z_i z^a`. Immediate from the first
branch.

**Lemma 3.4 (B).** `x_i · z^a − z_i z^a ∈ P_{≤|a|}`, by induction on `|a|`.

**Lemma 3.5 (C).** `x · (y · f) − y · (x · f) = ⁅x, y⁆ · f` for all `x, y ∈ L`,
`f ∈ P`.

This is the hard lemma, by induction on `|a|` with `f = z^a`, `x = x_i`,
`y = x_j`, `i > j` (the case `i = j` is trivial and the statement is
antisymmetric).

*Case `j ≤ a`.* Then `x_j · z^a = z_j z^a = z^{a+e_j}`, and `j = min supp(a+e_j)`
while `i > j` means the second branch of the definition applies to
`x_i · z^{a+e_j}`, giving exactly

```
x_i · (x_j · z^a) = z_j · (x_i · z^a) + ⁅x_i, x_j⁆ · z^a.
```

So the case reduces to `x_j · (x_i · z^a) = z_j · (x_i · z^a)`, i.e. to showing
that `x_j` acts as multiplication by `z_j` on `x_i · z^a`. That is *not*
automatic and is where the induction has to be strengthened; see "risk" below.

*Case `¬ (j ≤ a)`.* Put `j' := min supp a`, so `j' < j < i`. Then
`z^a = z_{j'} z^b = x_{j'} · z^b` with `b := a − e_{j'}` and `j' ≤ b`, so one may
rewrite `z^a` as `x_{j'} · z^b` and apply the induction hypothesis (C) in degree
`|b| = |a| − 1` twice, together with the Jacobi identity, to reduce to the first
case.

**Risk.** Lemma 3.5 is the classical sticking point (Humphreys §17.4, Jacobson
Ch. V). The naive induction does *not* close: in the first case one needs
`x_i · z^a` to lie in the span of `z^c` with `j ≤ c`, and that fails as soon as
`⁅x_i, x_{j'}⁆` has a component on some `x_k` with `k < j`. The fix in the
literature is to run (A), (B), (C) as a *simultaneous* induction on the degree
bound `m`, where (C) is only asserted for `|a| ≤ m − 1` while (A) and (B) are
asserted for `|a| ≤ m`, and to do the first case by a nested induction on `|a|`.
Budget the bulk of the implementation time here, and prove it on paper before
writing Lean.

**Theorem 3.6 (PBW).** The map `ev : U(L) → P`, `u ↦ u · 1`, is a `K`-linear
isomorphism carrying the ordered monomial `ι(x)^a` to `z^a + (terms of degree
< |a|)`. Consequently the ordered monomials form a `K`-basis of `U(L)`; in
particular `ι` is injective.

*Proof.* `ev(ι(x)^a) = z^a + lower` by (A) and (B) and induction. Triangularity
against the basis `{z^a}` of `P` gives that `{ev(ι(x)^a)}` is a basis of `P`, so
`ev` is surjective; and by Lemma 3.1 the `ι(x)^a` span `U(L)`, so `ev` is
injective too. ∎

### Step 4. `U(L)` is free over `Z₀ := K[c_1, …, c_n]`

**Lemma 4.1.** The ordered monomials `ι(x)^a` with `a_j < q` for every `j` form
a basis of `U(L)` as a `Z₀`-module.

*Proof sketch.* Transport along `ev`. `c_j` acts on `P` with
`c_j · f = z_j^q f + (terms of degree < |f| + q)` — the leading term because
`x_j · g = z_j g + lower` iterated `q` times, and the subtracted lower `p`-power
terms have degree `< q`. Spanning: induct on degree, using the leading term to
reduce. Independence: a nontrivial relation would have a nonzero leading term
`Σ_a (leading coeff) z^{a + q·b}`, and the pairs `(a, b)` with `a_j < q` index
distinct monomials `a + q·b`, so no cancellation is possible. ∎

**Corollary 4.2.** `ι(L) ∩ I = 0`. Indeed `ι(L)` is spanned by the basis
elements `ι(x_j)` (`a = e_j`, and `1 < q` since `m ≥ 1`), while `I` is the
`Z₀`-span of the same basis with a positive-degree coefficient. ∎

**Corollary 4.3.** `A = U(L)/I` has dimension `q^n` over `K`, and the induced
map `L → A` is an injective Lie morphism. ∎

### Step 5. Assembly

```lean
theorem hasFaithfulFinRep_charP (p : ℕ) [Fact p.Prime] [CharP K p]
    [FiniteDimensional K L] : HasFaithfulFinRep K L :=
  hasFaithfulFinRep_of_injective_toAlgebra A quotLieHom quotLieHom_injective

theorem hasFaithfulFinRep [FiniteDimensional K L] : HasFaithfulFinRep K L := by
  rcases CharP.char_is_prime_or_zero K (ringChar K) with hp | h0
  · exact hasFaithfulFinRep_charP _
  · haveI : CharZero K := ...
    exact hasFaithfulFinRep_charZero
```

`adoIwasawa` then follows exactly as `adoCharZero` does.
